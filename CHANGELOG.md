# Change Log

English | [简体中文](CHANGELOG.zh-CN.md)

All notable changes to the "quick-translation" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

## [0.8.6]

- Replaced the blue-violet gradient with a muted chartreuse, graphite, and warm-paper palette with subtle pencil hatching.

## [0.8.5]

- Restored both sparkle particles in the monochrome toolbar icon.
- Added a restrained blue-violet palette to the extension product icon.

## [0.8.4]

- Reworked the extension and toolbar icons around a Chinese translation glyph, `A`, and sparkle motif in a monochrome VS Code style.

## [0.8.3]

- Rebuilt the interlocking monogram on a 16px grid with consistent strokes, spacing, and optical weight.

## [0.8.2]

- Refined the monochrome icon into an interlocking `A / 文` monogram with a shared stroke.

## [0.8.1]

- Reworked all branding into a monochrome VS Code-style `A / 文` line icon.

## [0.8.0]

- Added a dedicated extension icon and matching light/dark editor toolbar icons.
- Replaced the globe command icon to avoid confusion with VS Code browser actions.

## [0.7.2]

- Added matching English and Simplified Chinese README and changelog documents.

## [0.7.1]

- Consolidated editor mutations into a dedicated module and aligned tests with source responsibilities.
- Enabled stricter TypeScript checks for unused code, implicit returns, and switch fallthrough.

## [0.7.0]

- Added global or current-workspace scope selection to the quick configuration flow.

## [0.6.0]

- Added atomic translation and replacement for multiple editor selections.
- Added default shortcuts for opening translation, translating selections, and configuration.

## [0.5.0]

- Added English and Simplified Chinese localization for runtime UI, commands, and settings.

## [0.4.0]

- Added a cancellable translate-and-replace command and shortcut.
- Preserved common comment, indentation, and string wrappers while replacing translations.
- Added provider health checks with latency and error details.

## [0.3.0]

- Added an editor selection context-menu command.
- Added a temporary target-language picker.
- Added retry-all, error details, and per-provider retry actions.

## [0.2.0]

- Added automatic translation for the active editor selection.
- Added result actions to copy, replace the selection, or insert below it.

## [0.1.0]

- Added real no-key web translation providers with automatic fallback: Microsoft, Google, Baidu.
- Added multilingual bidirectional settings and in-popup configuration actions.

## [0.0.1]

- Initial mock translation release.
